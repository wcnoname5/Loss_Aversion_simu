# R Simulation for Loss Aversion

This repository contains simulation code and results for comparing different
choice-based elicitation methods used to estimate indifference points and
loss aversion. For full motivation, methodology, and discussion, see
[the thesis dissertation](https://doi.org/10.6342/NTU202501601).

The benchmark is the non-parametric trade-off (TO) procedure of
[Abdellaoui et al. (2016)](https://doi.org/10.1007/s11166-016-9234-y).
On top of the *Bisection* method used in that paper, this project also
simulates the psychophysical methods *ASA*, *PEST*, and *MOBS*, plus a
simplified bisection ("HaB") variant.

## Requirements

- **R ≥ 4.2.3** (the included `run_simulations.sh` hard-codes a Windows
  path to `R-4.2.3`; edit it if your R lives elsewhere).
- Open the project via `loss aversion.Rproj` so that `here::here()`
  resolves correctly.
- CRAN packages used across the simulation and analysis scripts:

  ```
  R6, here, glue, magrittr, stringr, dplyr, tidyr, purrr,
  tibble, tidyverse, furrr, future, patchwork, kableExtra,
  DT, readxl
  ```

  Install missing ones with `install.packages(c("R6", "here", ...))`.

## Method-name glossary

Internal names in the simulation and labels used in the thesis/figures do
not always coincide. The mapping is:

| Internal name          | Paper / figure label | Meaning                                       |
| ---------------------- | -------------------- | --------------------------------------------- |
| `Bisection`            | `BiM`                | Bisection (Abdellaoui et al. 2016)            |
| `Bisection-Slider`     | `BiM-S`              | Bisection with a slider-based final response  |
| `MOBS`                 | `MOBS`               | Modified Binary Search                        |
| `ASA`                  | `ASA`                | Accelerated Stochastic Approximation          |
| `PEST`                 | `PEST`               | Parameter Estimation by Sequential Testing    |
| `SimpBisection`        | `HaB`                | Halved variant of Bisection (SimpBisection)   |
| `Bisection_mixASA`     | `BiM-ASA`            | Bisection that switches to ASA after 3 trials |

Suffixes that may be appended to any of the above:

- `_fixbnd` — fixed boundary width (e.g. 5000)
- `_randInit` — random initial point instead of equal-expectation
- `_adaptiveBnd` — adaptive boundary scheme (Only mentioned in discussion)
- `_earlyN` — terminated after N iterations (Study 2 only; `N ∈ {5, 10}`)

## Reproducing the simulation

Two options.

### Option A — one shot

From the repository root in a bash shell (Git Bash on Windows works):

```bash
./run_simulations.sh
```

This runs `Study1_simulation.R` and, if it succeeds, `Study2_simulation.R`.
Each writes a timestamped `.rds` into `simulated_data/` and a log into
`simulated_data/logs/`. Edit the hard-coded `Rscript.exe` path inside
the script if your R installation is elsewhere.

### Option B — from R/RStudio

```r
source(here::here("functions", "data_generation", "Study1_simulation.R"))
source(here::here("functions", "data_generation", "Study2_simulation.R"))
```

Both scripts skip work if their target `.rds` already exists — delete the
file to force a re-run.

### Knit the analysis

After the `.rds` files exist:

1. Open `Analysis_Rmds/Study1_latex.Rmd` and knit. Figures go to
   `Results_figs/`.
2. Open `Analysis_Rmds/Study2_latex.Rmd` and knit. The first knit will
   compute the loss-aversion table (`KT2()` over every simulated
   participant) and cache it as `simulated_data/Study2_LA_df.rds`;
   subsequent knits read from this cache. **Delete the cache to force
   recomputation** if you re-run the simulation.
3. `Empirical_Study.Rmd` and `AppendixA-BL2023_analysis.R` perform the
   empirical and appendix analyses and require the files in `data/`.

The Rmds pick the simulation file via
`list.files(...) %>% sort() %>% tail(1)`, i.e. the most recent timestamped
`.rds` matching `Study{1,2}_simulation_*.rds`. If you want a specific run,
either delete older files from `simulated_data/` or hard-code the filename
in the read chunk.

## Notes

- The `functions/` code has been substantially modified from the original
  paper to support adaptive boundary schemes for bisection-based methods,
  so generated data and figures will not match thesis exactly.
  For the original code and reproductions, switch branches:

  ```bash
  git checkout Archive
  ```

- `phi_calculator.R` is independent of the main pipeline. Given a target
  per-choice error rate, it solves for the softmax temperature `phi`
  used in the simulation. Use it if you want to change the `phi_vec`
  values inside the simulation scripts.

- Approximate runtimes on a typical laptop: Study 1 is the slower of
  the two (more methods × `Nsim = 1000` × 9 parameter cells). Expect
  the simulations to take on the order of an hour each; the Rmds knit
  in a few minutes once the `.rds` exists and `Study2_LA_df.rds` is
  cached.
